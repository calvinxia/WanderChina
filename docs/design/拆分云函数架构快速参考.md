## 核心架构

```
┌─────────────────────────────────────────────────────┐
│                  Flutter App                        │
└─────────────────────────────────────────────────────┘
       │                           │
       ▼                           ▼
┌────────────────┐          ┌────────────────┐
│  公网云函数      │          │  内网云函数      │
│  (无 VPC)      │          │  (VPC 启用)    │
└────────────────┘          └────────────────┘
       │                           │
       ▼                           ▼
  外部 API                    内网数据库
  (DeepSeek/百度)              (PostgreSQL/Redis)
```

**关键优势：**
- ✅ 节省 NAT 网关费用：**¥360/月 → ¥0**
- ✅ 架构更清晰：公网访问和内网访问分离
- ✅ 安全性更高：数据库凭证仅在内网函数中

## 云函数清单

### 公网函数（4个）- 不启用 VPC

| 函数名 | 用途 | 调用的 API |
|--------|------|-----------|
| `deepseek_translate` | 翻译文本 | DeepSeek API |
| `baidu_voice_asr` | 语音识别 | 百度语音 ASR |
| `baidu_voice_tts` | 语音合成 | 百度语音 TTS |
| `get_cos_token` | COS 凭证 | 腾讯云 STS |

**配置要点：**
```yaml
网络配置:
  VPC: 不启用  ← 关键
  
环境变量:
  DEEPSEEK_KEY:     sk-xxxxxxxx
  BAIDU_API_KEY:    xxxxxxxx
  BAIDU_SECRET_KEY: xxxxxxxx
  COS_SECRET_ID:    AKIDxxxxxxxx
```

### 内网函数（4个）- 启用 VPC

| 函数名 | 用途 | 访问的资源 |
|--------|------|-----------|
| `translate_db_write` | 保存翻译结果 | PostgreSQL + Redis |
| `create_trip` | 创建行程 | PostgreSQL |
| `user_auth` | 用户认证 | PostgreSQL + Redis |
| `get_user_data` | 获取用户信息 | PostgreSQL + Redis |

**配置要点：**
```yaml

  VPC: wanderchina-vpc
  子网: 应用子网（172.16.3.0/24）

  DB_PORT:       5432
  DB_NAME:       wanderchina
  DB_USER:       wc_scf_service
  DB_PASSWORD:   ScfService@2026#Secure
  REDIS_HOST:    172.16.2.x
  REDIS_PASSWORD: xxxxxxxx
```

## 完整翻译流程示例

```
用户看到 "故宫博物院"
    │
    ▼
【Flutter 调用 deepseek_translate（公网函数）】
    │
    ├─→ 调用 DeepSeek API
    │   输入: "故宫博物院"
    │   输出: "Palace Museum"
    │
    ▼
【Flutter 调用 translate_db_write（内网函数）】
    │
    ├─→ 写入 PostgreSQL poi_translations 表
    ├─→ 写入 Redis 缓存（24小时）
    │
    ▼
地图显示 "Palace Museum"
```

**Flutter 代码：**

```dart
// 1. 调用公网函数翻译
final response1 = await http.post(
  Uri.parse('https://service-abc123.gz.apigw.tencentcs.com/release/deepseek_translate'),
  body: json.encode({'text': '故宫博物院', 'target_lang': 'en'}),
);
final nameEn = json.decode(response1.body)['translated_text'];

// 2. 调用内网函数保存
await http.post(
  Uri.parse('https://service-def456.gz.apigw.tencentcs.com/release/translate_db_write'),
  body: json.encode({
    'poi_id': 'B000A8UJVW',
    'name_zh': '故宫博物院',
    'name_en': nameEn,
  }),
);
```

## 常见问题

### Q1: 公网函数无法访问 DeepSeek API？
**A:** 检查 VPC 是否**未启用**。如果误启用了 VPC，需要禁用。

### Q2: 内网函数无法连接数据库？
**A:** 检查：
1. VPC 是否**已启用**
2. DB_HOST 是否是**内网地址**（172.16.1.x）
3. 子网选择是否正确
4. 数据库安全组是否允许 VPC 内访问

### Q3: 如何测试公网函数？
**A:** 使用 Postman：
```bash
POST https://service-abc123.gz.apigw.tencentcs.com/release/deepseek_translate
Content-Type: application/json

{
  "text": "故宫",
  "target_lang": "en"
}

期望返回:
{
  "translated_text": "Forbidden City"
}
```

### Q4: 如何测试内网函数？
**A:** 使用 Postman：
```bash
POST https://service-def456.gz.apigw.tencentcs.com/release/translate_db_write
Content-Type: application/json

{
  "poi_id": "TEST001",
  "name_zh": "故宫",
  "name_en": "Forbidden City"
}

期望返回:
{
  "success": true
}

然后到 pgAdmin 检查数据库是否有记录
```
